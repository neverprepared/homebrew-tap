# homebrew-tap

Homebrew tap for [neverprepared](https://github.com/neverprepared) tools.

## Install

```sh
brew tap neverprepared/tap
brew install mcp-slack
```

## Tools

| Formula | Description |
|---|---|
| `mcp-slack` | MCP server for Slack — messages, channels, users, files, reactions, pins, and search |
